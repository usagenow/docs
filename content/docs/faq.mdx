title: FAQ
description: Short answers to common questions about UsageNow.
---

### Does UsageNow upload my prompts?

No. UsageNow never stores or uploads prompts, responses, or conversation content. See [Privacy](/privacy).

### Does UsageNow read my source code?

No. From session files, UsageNow reads only timestamps, identifiers, model names, token counts, and rate limits. Lines with conversation content are skipped.

### Why does Claude sometimes show “Usage limits unavailable”?

Because Claude Code does not currently expose quota through a supported local API, and the optional experimental quota source may be turned off or may not have a current access token. Local activity still appears. See [Claude Code](/providers/claude-code#states).

### Does UsageNow modify Claude credentials?

No. UsageNow never refreshes, modifies, or stores your Claude Code credentials.

### Does UsageNow read my Codex credentials?

No. Codex’s own app-server signs in with Codex’s credentials. UsageNow only asks it for your rate limits.

### What does “58% left” mean?

58% of that usage window remains; you have used 42%. That's the default. If you'd rather see what's used, choose **Settings › General › Show limits as › Used**, and it reads **42% used** everywhere — popover, menu bar, and widget. See [Left or used](/menu-bar#left-or-used).

### Can I see more than today?

Yes. Under each provider, a chart shows the last 30 days, one bar per day, with the month's tokens or credits, estimated cost, and most used model. Hover a bar to see that day. See [Last 30 days](/menu-bar#last-30-days).

### How do I report a problem?

Choose **Settings › About › Report a Problem**. It shows the whole report first — versions, screen sizes, settings, and what each provider shows — and opens a prefilled GitHub issue or email for you to send. Names, emails, file paths, keys, and prompts are never in it.

### Is the cost estimate what I'm being charged?

No. Your subscription doesn't charge per token, and UsageNow never sees a bill or an invoice. The estimate is what today's tokens would have cost through the provider's API, at published prices — a sense of scale for a day's work. See [Estimated cost](/menu-bar#estimated-cost).

### Does UsageNow update itself?

From 0.4.0, yes, if you let it. It installs only updates carrying UsageNow's signature, and checking for one sends nothing about you. See [Updates](/installation#updates).

### Why don’t token counts match my plan’s usage?

Token and request counts are local activity recorded on this Mac. They include cached input and don’t include other devices, so they don’t necessarily match quota consumption or billing.

### Why are provider values different?

Different providers expose different quota systems and usage windows. Their percentages aren’t directly comparable.

### Do I need an account?

No. UsageNow has no accounts.

### Is UsageNow open source?

Yes. The source code is available on [GitHub](https://github.com/usagenow/usagenow) under the MIT License.

### Will UsageNow support more providers?

Yes. 0.5.0 added Kiro, Warp, DeepSeek, Kimi, and OpenRouter; 0.6.0 added OpenCode, Qoder, and Ollama Cloud. Cursor, GitHub Copilot, and Qwen are planned; see [Coming Soon](/providers/coming-soon). New providers are added when reliable, privacy-respecting data exists.

### Is there a Windows or Linux version?

No. UsageNow currently focuses on macOS.

### Is there a command-line tool?

A CLI is planned.

### Where can I download UsageNow?

From [usagenow.com](https://usagenow.com) or the [releases page](https://github.com/usagenow/usagenow/releases). [Installation](/installation) lists every official channel and how to build UsageNow from source.
