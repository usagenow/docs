## Requirements

<Requirements />

UsageNow reads data from the AI coding tools you already use, so install and sign in to at least one of them first. You can add or remove providers at any time.

## Download

Download UsageNow from [usagenow.com](https://usagenow.com) — the button gives you [usagenow.dmg](https://usagenow.com/download/usagenow.dmg), always the current release — or pick a specific version from the [releases page](https://github.com/usagenow/usagenow/releases). Open the image and drag UsageNow to Applications. The app is signed with a Developer ID and notarized by Apple, so it opens without a Gatekeeper warning.

UsageNow lives in the menu bar and has no Dock icon. Click its symbol to open the popover, and continue with [Getting Started](/getting-started).

## Updates

From 0.4.0, UsageNow updates itself. It checks for a new version, shows you what changed, and installs it when you agree. **Settings › General › Updates** has the switch and a **Check Now** button.

An update is installed only when it carries UsageNow's own signature, made with a key that exists in one place: its maintainer's keychain. Nothing in the public repository can produce an update UsageNow accepts, and a build that didn't come from the release process can't update itself at all.

A check is a plain request for the update feed at `usagenow.com`. Sparkle's system profiling is switched off, so nothing about your Mac, your version, or you is sent with it.

<Callout type="info" title="Coming from 0.3.0 or earlier">
  Those versions have no updater, so install 0.4.0 by hand once — download it and drag it to Applications, replacing the old copy. Later versions arrive on their own.
</Callout>

## Build from source

You can also build UsageNow yourself — to contribute, or to run an unreleased change. You need Xcode 26 or later.

<Steps>

### Clone the repository

```bash
git clone https://github.com/usagenow/usagenow.git
cd usagenow
```

### Open the project

Open `UsageNow.xcodeproj` in Xcode.

```bash
open UsageNow.xcodeproj
```

### Build and run

Select the **UsageNow** scheme and choose **Product › Run** (<Kbd>⌘R</Kbd>). The UsageNow symbol appears in the menu bar. Click it to open the popover.

</Steps>

To build from Terminal instead:

```bash
xcodebuild -project UsageNow.xcodeproj -scheme UsageNow build
```

Continue with [Getting Started](/getting-started) once the app is running.

### Enable the widget in a local build

The desktop widget reads data through an App Group, and App Groups require a signing team. Builds without one work normally, but the widget only shows **Open UsageNow to load usage data.** To enable it, build with your own team ID:

```bash
xcodebuild -project UsageNow.xcodeproj -scheme UsageNow \
    DEVELOPMENT_TEAM=YOURTEAMID \
    USAGENOW_APP_GROUP=YOURTEAMID.group.com.usagenow.UsageNow \
    USAGENOW_APP_ENTITLEMENTS=Config/UsageNow.entitlements \
    USAGENOW_WIDGET_ENTITLEMENTS=Config/UsageNowWidget.entitlements \
    build
```

You can set the same four build settings once in Xcode instead. See the [repository README](https://github.com/usagenow/usagenow#readme) for more.

### Update a source build

Pull the latest changes and build again:

```bash
git pull
```

## Uninstall

UsageNow doesn’t change any Codex or Claude Code files, so removing it leaves your tools exactly as they were.

1. If you added the UsageNow widget, remove it from your desktop.
2. If Launch at Login is on, turn it off in **Settings › General** so macOS removes the login item.
3. Click **Quit** in the popover, or press <Kbd>⌘Q</Kbd> while it’s open.
4. Delete UsageNow.app.

To also remove UsageNow’s preferences, run:

```bash
defaults delete com.usagenow.UsageNow
```
