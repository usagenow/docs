UsageNow is a native macOS menu bar app for people who build with AI coding tools. It brings reported limits, reset times, and local activity together, without a UsageNow account. [Supported providers](/providers) include Codex, Claude Code, Gemini CLI, Antigravity, Windsurf, Cursor, GitHub Copilot, Perplexity, ElevenLabs, Z.ai, and more.

## New in 0.9.0

- [Personal widgets](/widgets#personalize-each-widget), with independent provider and account choices, and a new Large size.
- [Quota pace](/menu-bar#quota-pace): a local chart and a clearly labelled estimate from fresh quota readings, never token counts.
- Optional [service incidents](/menu-bar#service-incidents), off by default.
- [Antigravity CLI fallback](/providers/antigravity#cli-fallback) when the IDE cannot answer.
- Experimental [JetBrains AI](/providers/jetbrains) local quota; active-subscription validation remains pending.
- **Dutch / Nederlands**, bringing the app and website to ten languages, and refreshed Windsurf and ElevenLabs icons.

## Why UsageNow exists

AI coding tools meter usage in windows, such as a 5-hour window and a weekly one. When a window runs out in the middle of a task, you have to wait for it to reset. Each tool reports its limits differently, and checking them usually means switching context: running a command, opening a web page, or waiting for a warning.

UsageNow puts that information in the menu bar, for every tool you use, one click away. See what’s left, and keep building.

## Local-first

UsageNow works from information that already exists on your Mac:

- the official Codex app-server, which comes with Codex
- the session files Codex, Claude Code, Gemini CLI, Kiro, Qoder, Qwen Code, Cline, and Grok Build write as you work
- Warp's and OpenCode's own local databases, and the usage limits Kiro writes to its own log
- the account profile Claude Code keeps in its own configuration
- the Antigravity app's local server, or the official CLI's read-only usage report
- Windsurf's locally cached plan, without reading its sign-in
- JetBrains AI Assistant quota cached by the IDE, without credentials or network access

You don’t need a UsageNow account, and no UsageNow server receives your usage data. Optional connections ask the provider directly with the key, token, or web session you explicitly add; experimental Claude limits use its existing sign-in only if you turn the setting on. See [connection privacy](/providers/connections#where-credentials-go).

<Callout type="privacy">
  UsageNow never stores or uploads your prompts, source code, or conversations. [Privacy](/privacy) explains exactly what is read and where it goes.
</Callout>

## Platform

UsageNow currently focuses on macOS. It requires macOS 15 or later and is built with Swift 6 and SwiftUI, so it looks and behaves like the rest of your Mac — including light and dark appearance.
