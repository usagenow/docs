A provider is an AI coding tool UsageNow can report on. Each one exposes different information, so UsageNow shows only what a provider actually reports.

## Turning a provider off

Every available provider is on by default. Turn any one on or off in **Settings › Providers**, and drag providers into the order the popover and widget should use.

When a provider is off, UsageNow doesn’t:

- refresh the provider
- access the provider’s local files
- access the provider’s credentials
- include the provider’s values in menu bar calculations
- include the provider in widget data

UsageNow never deletes or changes anything belonging to a provider when you turn it off. Turning it back on picks up where things are.

## How data differs between providers

Providers measure usage in their own ways, so their numbers aren’t directly comparable:

- **Windows differ.** One provider may report a 5-hour and a weekly window; another may report only one, or a window for a single model family.
- **Sources differ.** Codex reports limits through its own app-server; Claude Code through an [experimental source](/providers/claude-code#experimental-usage-limits); Antigravity through its app’s local server while it runs. Gemini CLI reports no limits.
- **Local activity is separate.** Tokens and requests come from session files on your Mac and aren’t the same as quota consumption. Where a provider records the model, UsageNow also shows [activity by model](/menu-bar#models-today).

UsageNow never fills a gap with an estimate. When a value isn’t reported, it isn’t shown.
