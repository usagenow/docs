## More than one account

Codex, Claude Code, and the API key providers can show several accounts side by side — a personal and a work Codex, say, or two DeepSeek keys. Add them in **Settings › Providers**; see [Accounts](/settings#accounts).

## Turning a provider off

Every provider that reads a tool on your Mac is on by default, and appears once the tool is installed. Providers that need your API key start off. Turn any one on or off in **Settings › Providers**, and drag providers into the order the popover and widget should use.

When a provider is off, UsageNow doesn’t:

- refresh the provider
- access the provider’s local files
- access the provider’s credentials
- include the provider’s values in menu bar calculations
- include the provider in widget data

UsageNow never deletes or changes anything belonging to a provider when you turn it off. Turning it back on picks up where things are.

## How data differs between providers

Providers measure usage in their own ways, so their numbers aren’t directly comparable:

- **Windows differ.** One provider may report a 5-hour and a weekly window; another may report only one, or a window for a single model family.
- **Sources differ.** Codex reports limits through its own app-server; Claude Code through an [experimental source](/providers/claude-code#experimental-usage-limits); Antigravity through its app’s local server while it runs; Kiro through the limits it writes to its own log; Ollama Cloud through an [experimental endpoint](/providers/api-keys#ollama-cloud). Gemini CLI, Warp, OpenCode, Qoder, Qwen Code, Cline, and Grok Build report no limits. DeepSeek, Kimi, and OpenRouter report money rather than a percentage.
- **Meters differ.** Most tools count tokens. Kiro and Qoder count credits, and Warp counts both. The [30-day history](/menu-bar#last-30-days) charts each tool in its own unit.
- **Local activity is separate.** Tokens and requests come from session files on your Mac and aren’t the same as quota consumption. Where a provider records the model, UsageNow also shows [activity by model](/menu-bar#models-today).

UsageNow never fills a gap with an estimate. When a value isn’t reported, it isn’t shown.
