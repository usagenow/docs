## Now available in 0.8.0

Cursor and GitHub Copilot are no longer Coming soon. Version 0.8.0 adds six providers:

- [Windsurf](/providers/windsurf) — local cached limits.
- [Cursor](/providers/cursor) — experimental personal-plan usage with a web session.
- [GitHub Copilot](/providers/github-copilot) — experimental allowances with your own GitHub token.
- [Perplexity](/providers/perplexity) — experimental web credits with a web session.
- [ElevenLabs](/providers/elevenlabs) — monthly characters through the official subscription API.
- [Z.ai](/providers/zai) — experimental global Coding Plan quotas.

The five explicit connections start off. See [Connect a provider](/providers/connections) for setup and limitations.

## What comes next

No further provider or release date is promised here. An integration is added only when useful data can be read reliably with clear permission. The [overview](/providers) lists what the released app actually supports.

If you know a useful data source or want to suggest a tool, [open an issue](https://github.com/usagenow/usagenow/issues). Never include keys, tokens, session cookies, or private account data. Integrations are welcome contributions — see [Contributing](/contributing).
