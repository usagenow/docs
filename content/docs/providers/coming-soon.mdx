These providers are planned. They aren’t supported in UsageNow today.

| Provider | Status |
| --- | --- |
| Cursor | <Badge variant="planned">Coming soon</Badge> |
| GitHub Copilot | <Badge variant="planned">Coming soon</Badge> |
| Qwen | <Badge variant="planned">Coming soon</Badge> |

Provider support depends on whether reliable and privacy-respecting usage data can be obtained. GitHub Copilot is planned through GitHub’s official premium request usage API, with a token you provide. There are no release dates.

## In the app

These providers appear in **Settings › Providers** under **Coming soon**. They’re labels only: they can’t be turned on, and there’s no integration behind them — no credentials, no file access, and no network requests.

## Suggest or build a provider

If you’d like UsageNow to support a tool, or you know how it reports usage, [open an issue](https://github.com/usagenow/usagenow/issues) on GitHub. Provider integrations are welcome contributions — see [Contributing](/contributing).
